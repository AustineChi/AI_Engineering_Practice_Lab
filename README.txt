AI ENGINEERING PRACTICE LAB — 303 QUESTIONS

WHAT'S INCLUDED
- 303 multiple-choice questions: the original 200 plus 103 new questions based on the two supplied PDFs.
- Learning mode: hints, immediate feedback, explanations and practical takeaways.
- Exam mode: no hints or answer explanations until the round is complete.
- Topic selection and scenario/concept/core question labels.
- Review mistakes and bookmarked questions.
- Confidence ratings (low / medium / high).
- Dashboard with overall accuracy, attempted questions, mastery estimate and topic progress.
- Reset all progress and start from scratch.
- Light and dark themes.
- One question at a time, shuffled, with session scoring.

SOURCE COVERAGE
New questions draw on:
- AI Systems Engineering: Master Blueprint (uploaded PDF)
- AI Evals: The Hands On Playbook (uploaded PDF)

The 103 additions are original practice questions based on concepts and scenarios in those documents. They are not verbatim extracts. The original 200 questions are retained.

RUNNING
Python 3 is required. No third-party packages or internet connection are required.
- Windows: double-click start_quiz.bat
- macOS: double-click start_quiz.command (you may need to allow it in Security & Privacy)
- Linux: run ./start_quiz.sh

The launcher starts a local web server and opens the quiz in your browser.
Do not open index.html directly; the browser may block loading questions.yaml.

PROGRESS AND RESET
Progress, confidence ratings and bookmarks are stored in this browser's local storage.
Use "Reset all progress and start from scratch" on the dashboard to clear them.
The reset does not delete or alter the question bank and does not change the theme preference.

QUESTION BANK FORMAT
questions.yaml is JSON-compatible YAML 1.2. The page reads it as JSON, so there is no external YAML parser dependency.
